## حدود قائمة معروفة

- Excel/CSV import غير متاح؛ إدخال العمال يدوي.
- واجهة التبرير والتسوية، اختيار يوم سابق، شرائط تحذير السكن/الفريق غير المسجل،
  والتصدير لم تكتمل.
- تعديل/تعطيل العامل، إدارة فترات التوظيف والتصنيف، الدخول/الأدوار المحلية،
  النسخ/الاستعادة، وتوقيع إنتاجي/معرّف نهائي لم تكتمل.
- المزامنة السحابية مؤجلة بقرار المالك؛ لا تهيئ Supabase ولا تتصل بالإنترنت.
- ADB لم يعمل ضمن مضيف التنفيذ بسبب مسار `.android`؛ اختبار الهاتف يتم بواسطة
  المالك مباشرة. يلزم منه فحص وضع الطيران وإعادة فتح التطبيق بعد حفظ بيانات.

1. انتظر من المالك نتيجة APK أعلاه، واطلب منه تجربة إضافة فريق وسكن وعامل،

   `file_picker` (لا توجد حاليًا في dependencies). بعد الإذن نفذ استيرادًا
   بمعاينة وتحقق من الأكواد المكررة والأسماء الإلزامية ومعاملة آمنة وتقارير صفوف
   مرفوضة بلا مسح البيانات الموجودة.
3. أكمل شاشات PRD المتبقية، مع اختبارات في طبقة البيانات ومحرك الحالة وتحديث
   ملفات `docs/` في كل خطوة.

   نفّذ الرفع إلى GitHub بطلب المالك السابق. لا ترفع APK أو مفاتيح توقيع أو كاش.
