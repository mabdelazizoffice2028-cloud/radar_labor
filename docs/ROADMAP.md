# خارطة طريق رادار ليبور

**آخر تحديث:** 25 أكتوبر 2026. اكتمل تنفيذ رادار ليبور V1.5 بالكامل (المرحلة أ والمرحلة ب — الجلسات 0 إلى 11). التطبيق إنجليزي افتراضيًا وعربي/RTL، بقاعدة Drift مشفرة محلية (`schemaVersion=5`) وأصول مضمنة، مع فصل صارم للصلاحيات، ومعالج إعداد الفريق، والتسجيل اليومي الذكي والفروقات وحل التعارض المحلي، والسجل التاريخي، وتدفق الدخول الموجه بالدور، وسجل التدقيق الإداري، ومسح القوى المحمي، ومحرك المزامنة التلقائية المحلي أولًا.

| المرحلة | الحالة | المطلوب لإغلاقها |
| --- | --- | --- |
| S0 — الأساس والتشفير | مكتمل | قاعدة Drift مشفرة، مخطط وترحيل حتى `schemaVersion=5`، وفحوصات أساسية موثقة |
| S1 — وقت العمل والأحداث والحالات | مكتمل | الساعة/تاريخ الرياض، نماذج ومحرك حالة نقي، مستودع أحداث متزايد التسلسل مع `userId`، وربط لوحة الحالات |
| S2 — تشغيل وبيانات محلية ومزامنة | مكتمل محليًا | مفتاح قاعدة آمن وفتح محلي وإعدادات، ومحرك المزامنة التلقائية `SyncEngine` مع `OutboxRepository` و `RemoteSyncGateway` |
| S3 — الإعداد والعمال والفرق | مكتمل | الفرق والمساكن والعمال واستيراد XLSX/CSV محليًا مع إعادة التفعيل، ومعالج إعداد الفريق وتعديل أعضائه، وأرشفة العامل بدل الحذف، ومسح القوى المحمي بتصدير نسخة احتياطية وتأكيد نصي |
| S4 — مراجعة السكن | مكتمل ومختبر | اختيار المبنى، تعليم الغائبين، حفظ فحص «لا غائبين»، تأكيد الأسماء، تراجع بأحداث عكسية، وملخص واتساب محلي قابل للنسخ |
| S5 — التسجيل اليومي الذكي للموقع | مكتمل ومختبر | أولويات التحميل الأربع، المسودات التلقائية، إضافة عامل ضيف ليوم واحد، معاينة الفروقات قبل الحفظ، حل التعارض المحلي، والتراجع الذري الشامل (`LedgerUndoPlan`) |
| S6 — لوحة الحالة والسجل التاريخي | مكتمل ومختبر | 5 بطاقات حالة، أسماء المشرفين المسؤولين في «لم يسجَّل بعد»، شاشة السجل التاريخي للمشرف والإدارة مع التعديل خلال 7 أيام، وتبويب «سجل التغييرات» (`AuditLogTabView`) |
| S7 — الدخول الموجه بالدور وإدارة الحسابات | مكتمل ومختبر؛ APK Release مبني ومفحوص | اختيار الدور -> اختيار الاسم -> رقم السر، إنشاء مشرف موقع بلا فريق مبدئي، إعادة تعيين كلمة المرور وتعطيل الحساب، ودعم حساب `viewer` بلا سجل عامل. اجتازت الاختبارات **125/125** والتحليل نظيف (`No issues found!`) |
| Supabase / RLS | الخطة الأمنية والمحرك مكتملان؛ النشر البعيد بانتظار المالك | الخطة الأمنية الكاملة في `docs/SECURITY_AND_SYNC_PLAN_V1_5.md`؛ يظل تطبيق SQL على مشروع Supabase المستضاف خطوة نشر مستقلة بيد المالك |
