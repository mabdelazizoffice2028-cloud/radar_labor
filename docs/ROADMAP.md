# خارطة طريق رادار ليبور

**آخر تحديث:** 23 أكتوبر 2026. الهدف الحالي حسب طلب المالك: تطبيق عربي/إنجليزي محلي بالكامل وقت التشغيل، يبدأ دون إنترنت، مع بيانات مشفرة وأصول مضمنة. المزامنة السحابية مؤجلة.

| المرحلة | الحالة | المطلوب لإغلاقها |
| --- | --- | --- |
| S0 — الأساس والتشفير | مكتمل | قاعدة Drift مشفرة، مخطط وترحيل، وفحوصات أساسية موثقة |
| S1 — وقت العمل والأحداث والحالات | النواة مكتملة، ربط الواجهة جارٍ | الساعة/تاريخ الرياض، نماذج ومحرك حالة نقي، مستودع أحداث متزايد التسلسل، وربط لوحة الحالات؛ بقي اختبار دورة البيانات على الهاتف والتبرير/الحسم واختيار التاريخ |
| S2 — تشغيل وبيانات محلية | جزئي | مفتاح قاعدة آمن وفتح محلي وإعدادات؛ مطلوب تحقق استمرار البيانات بعد إغلاق التطبيق وإدارة النسخ/الاسترجاع |
| S3 — الإعداد والعمال | جزئي | واجهات إنشاء الفرق والمساكن والعامل وإسناده؛ مطلوب تعديل/تعطيل مرجعي، تصنيف العامل وفترات التوظيف والدخول المحلي إن طلبه المالك |
| S4 — مراجعة السكن | منفذ محليًا، ينتظر تجربة المالك | اختيار المبنى، تعليم الغائبين، حفظ فحص «لا غائبين»، تأكيد الأسماء، تراجع بأحداث عكسية، وملخص محلي قابل للنسخ؛ يلزم اختبار الاستخدام الفعلي |
| S5 — تسجيل الموقع | منفذ محليًا، ينتظر تجربة المالك | اختيار الفريق، تحديد الحاضرين، إرسال حتى بصفر حضور، تصحيح وتراجع كسجل أحداث؛ يلزم اختبار الاستخدام الفعلي |
| S6 — لوحة الحالة والتقارير | جزئية ومربوطة بالمحرك | تعرض 4 حالات + لم يسجل، مجهولين، مؤقت SLA والتعارضات على تاريخ العمل الحالي؛ بقي اختيار التاريخ وشرائط المباني/الفرق غير المسجلة وصفحة تسوية وتصدير |
| S7 — التقوية والتسليم | جارٍ | `dart analyze` بلا ملاحظات، 61 اختبارًا ناجحًا، والمالك أكد فتح الواجهة بصور الهاتف؛ بعد دفعة الشاشات الحالية يلزم APK جديد وتجربة إجراءات السكن/الموقع، حفظ البيانات بعد الإغلاق، ووضع الطيران والتوقيع النهائي |
| المزامنة السحابية | مؤجلة بقرار المالك | لا تبدأ إلا بطلب صريح؛ يجب أن يظل التسجيل المحلي مستقلًا عن الشبكة |

لا تُغلق مرحلة بوجود الشاشة وحدها. يجب مطابقة قبول PRD، والتحقق من السلوك، وتسجيل أدلة الفحوصات والبناء في `WORKLOG.md` و`BUGS.md`.
