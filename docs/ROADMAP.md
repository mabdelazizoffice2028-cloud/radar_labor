# خارطة طريق رادار ليبور

**آخر تحديث:** 26 أكتوبر 2026. اكتملت التحديثات الشاملة (المراحل 1-6 والتنقيح النهائي للبساطة والأيقونة المتجهة الرسمية). التطبيق إنجليزي افتراضيًا وعربي/RTL، بقاعدة Drift مشفرة محلية (`schemaVersion=5`) وأصول مضمنة، مع فصل صارم للصلاحيات، ومعالج إعداد الفريق، والتسجيل اليومي الذكي ومسودات السكن ثلاثية الحالات والبحث الداخلي، وبطاقة مهام المشرف، وحل التعارض المبسط، وتدفق الدخول الذكي، وأيقونة Android المتجهة الرسمية، وشريط AppBar مبسط وخالٍ من الفوضى.

| المرحلة | الحالة | المطلوب لإغلاقها |
| --- | --- | --- |
| S0 — الأساس والتشفير | مكتمل | قاعدة Drift مشفرة، مخطط وترحيل حتى `schemaVersion=5`، وفحوصات أساسية موثقة |
| S1 — وقت العمل والأحداث والحالات | مكتمل | الساعة/تاريخ الرياض، نماذج ومحرك حالة نقي، مستودع أحداث متزايد التسلسل مع `userId`، وربط لوحة الحالات |
| S2 — تشغيل وبيانات محلية ومزامنة | مكتمل محليًا | مفتاح قاعدة آمن وفتح محلي وإعدادات، ومحرك المزامنة التلقائية `SyncEngine` مع `OutboxRepository` و `RemoteSyncGateway` |
| S3 — الإعداد والعمال والفرق | مكتمل | الفرق والمساكن والعمال واستيراد XLSX/CSV محليًا مع إعادة التفعيل، ومعالج إعداد الفريق وتعديل أعضائه، وأرشفة العامل بدل الحذف، ومسح القوى المحمي بتصدير نسخة احتياطية وتأكيد نصي |
| S4 — مراجعة السكن | مكتمل ومختبر | فحص السكن ثلاثي الحالات (غير مراجع / مراجع / غائب)، المسودات المحلية التلقائية، زر تعليم الباقي، والبحث المباشر بالاسم والكود |
| S5 — التسجيل اليومي الذكي للموقع | مكتمل ومختبر | أولويات التحميل الأربع، المسودات التلقائية، البحث المباشر، تحديد الكل للصفوف المعروضة فقط، وحل التعارض المبسط، والتراجع الذري الشامل |
| S6 — لوحة الحالة والسجل التاريخي | مكتمل ومختبر | 5 بطاقات حالة، شريط مهام المشرف اليومي مع العدادات الحية، شاشة السجل التاريخي للمشرف والإدارة مع التعديل خلال 7 أيام، وتبويب سجل التغييرات |
| S7 — الدخول الموجه والدخول بالرمز السري | مكتمل ومختبر | تذكر الحساب المسجل، شاشة إدخال الرمز السري الفوري، إمكانية تبديل الحساب، وإدارة الحسابات |
| واجهة مبسطة وأيقونة متجهة | مكتمل ومختبر | شريط AppBar نظيف يقتصر على شارة المزامنة وتاريخ العمل، وأيقونة متجهة Vector رسمية تجمع الرادار وخوذة العمل |
| Supabase / RLS | الخطة الأمنية والمحرك مكتملان؛ النشر البعيد بانتظار المالك | الخطة الأمنية الكاملة في `docs/SECURITY_AND_SYNC_PLAN_V1_5.md`؛ يظل تطبيق SQL على مشروع Supabase المستضاف خطوة نشر مستقلة بيد المالك |
