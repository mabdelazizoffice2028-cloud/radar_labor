# خارطة طريق رادار ليبور

**آخر تحديث:** 23 أكتوبر 2026. توجيه المالك الأخير يطلب إكمال كل V1 الآن، ويحل محل طلب التوقف السابق بعد S6. التطبيق محلي بالكامل وقت التشغيل، إنجليزي افتراضيًا وعربي/RTL، ببيانات مشفرة وأصول مضمنة. المزامنة السحابية مؤجلة.

| المرحلة | الحالة | المطلوب لإغلاقها |
| --- | --- | --- |
| S0 — الأساس والتشفير | مكتمل | قاعدة Drift مشفرة، مخطط وترحيل، وفحوصات أساسية موثقة |
| S1 — وقت العمل والأحداث والحالات | النواة مكتملة، ربط الواجهة جارٍ | الساعة/تاريخ الرياض، نماذج ومحرك حالة نقي، مستودع أحداث متزايد التسلسل، وربط لوحة الحالات؛ بقي اختبار دورة البيانات على الهاتف |
| S2 — تشغيل وبيانات محلية | جزئي | مفتاح قاعدة آمن وفتح محلي وإعدادات؛ مطلوب تحقق استمرار البيانات بعد إغلاق التطبيق وإدارة النسخ/الاسترجاع |
| S3 — الإعداد والعمال | منفذ جزئيًا | الفرق والمساكن والعمال واستيراد XLSX/CSV محليًا، حسابا الإدارة وإدارة حسابات المستخدمين، أدوار ونطاقات المشرفين. تعديل/تعطيل المرجع وإدارة فترات العمل المتقدمة لاحقة |
| S4 — مراجعة السكن | منفذ محليًا، ينتظر تجربة المالك | اختيار المبنى، تعليم الغائبين، حفظ فحص «لا غائبين»، تأكيد الأسماء، تراجع بأحداث عكسية، وملخص محلي قابل للنسخ؛ يلزم اختبار الاستخدام الفعلي |
| S5 — تسجيل الموقع | منفذ محليًا، ينتظر تجربة المالك | اختيار الفريق، تحديد الحاضرين، إرسال حتى بصفر حضور، تصحيح وتراجع كسجل أحداث؛ يلزم اختبار الاستخدام الفعلي |
| S6 — لوحة الحالة والرسائل | مكتملة ومختبرة | 5 بطاقات حالة، اختيار تاريخ، تنبيهات المباني والفرق غير المسجلة، مجهولون ومؤقت SLA، تعارضات وتسويات محلية، ورسائل نسخ. controller يعزل منطق الرسائل والتاريخ والحفظ |
| S7 — الدخول والأدوار والاستيراد | منفذ ومختبر؛ APK Release مبني ومفحوص | دخول محلي، تغيير إلزامي لكلمة البداية، إدارة المستخدمين وإسناد نطاق المشرف، قراءة roster XLSX/CSV محليًا دون ID No، migration v3. اجتازت الاختبارات 73/73 والتحليل نظيف؛ اكتمل APK والفحص الآلي؛ تجربة الهاتف بانتظار المالك |
| المزامنة السحابية | مؤجلة بقرار المالك | لا تبدأ إلا بطلب صريح؛ يجب أن يظل التسجيل المحلي مستقلًا عن الشبكة |

V1 جاهز للتجربة. التحقق من التثبيت على جهاز المالك/ADB يبقى خارج هذا المضيف؛ سجّل نتيجة التجربة قبل اعتبار التسليم الميداني معتمدًا.
