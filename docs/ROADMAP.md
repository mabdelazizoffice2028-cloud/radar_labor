# خارطة طريق رادار ليبور

**آخر تحديث:** 23 أكتوبر 2026. الهدف الحالي حسب طلب المالك: تطبيق عربي/إنجليزي محلي بالكامل وقت التشغيل، يبدأ دون إنترنت، مع بيانات مشفرة وأصول مضمنة. المزامنة السحابية مؤجلة.

| المرحلة | الحالة | المطلوب لإغلاقها |
| --- | --- | --- |
| S0 — الأساس والتشفير | مكتمل | قاعدة Drift مشفرة، مخطط وترحيل، وفحوصات أساسية موثقة |
| S1 — وقت العمل والأحداث والحالات | النواة مكتملة، ربط الواجهة جارٍ | الساعة/تاريخ الرياض، نماذج ومحرك حالة نقي، مستودع أحداث متزايد التسلسل، وربط لوحة الحالات؛ بقي اختبار دورة البيانات على الهاتف |
| S2 — تشغيل وبيانات محلية | جزئي | مفتاح قاعدة آمن وفتح محلي وإعدادات؛ مطلوب تحقق استمرار البيانات بعد إغلاق التطبيق وإدارة النسخ/الاسترجاع |
| S3 — الإعداد والعمال | جزئي | واجهات إنشاء الفرق والمساكن والعامل وإسناده؛ مطلوب تعديل/تعطيل مرجعي، تصنيف العامل وفترات التوظيف. تسجيل دخول محلي بأدوار الإدارة ومشرف السكن ومشرف الموقع والمراقب للقراءة فقط مطلوب ضمن V1، لكنه لم يُنفذ؛ انظر PRD §1 وملحق الصلاحيات. إدارة المستخدمين داخل التطبيق مؤجلة إلى V1.1 |
| S4 — مراجعة السكن | منفذ محليًا، ينتظر تجربة المالك | اختيار المبنى، تعليم الغائبين، حفظ فحص «لا غائبين»، تأكيد الأسماء، تراجع بأحداث عكسية، وملخص محلي قابل للنسخ؛ يلزم اختبار الاستخدام الفعلي |
| S5 — تسجيل الموقع | منفذ محليًا، ينتظر تجربة المالك | اختيار الفريق، تحديد الحاضرين، إرسال حتى بصفر حضور، تصحيح وتراجع كسجل أحداث؛ يلزم اختبار الاستخدام الفعلي |
| S6 — لوحة الحالة والتقارير | مكتمل برمجيًا؛ ينتظر تجربة المالك | 5 بطاقات حالة، اختيار تاريخ، تنبيهات المباني والفرق غير المسجلة، مجهولون ومؤقت SLA، تعارضات مع تسوية، وتبرير محلي؛ لا يشمل تصدير التقارير. تحليل نظيف، 66 اختبارًا ناجحًا، وAPK Release جديد. لا تبدأ S7 قبل تجربة المالك |
| S7 — الدخول والأدوار والتقوية والتسليم | لم يبدأ | بعد قبول APK S6: تنفيذ الدخول المحلي بأربعة أدوار وربط صلاحيات كل دور ببياناته، وتجربة الحسابات الأولية/تغيير كلمة السر وفق PRD والمسودة التي ستراجع. ثم استكمال بيانات العمال، واختبارات استمرارية البيانات ووضع الطيران، وهوية التطبيق والتوقيع الإنتاجي عند الجاهزية |
| المزامنة السحابية | مؤجلة بقرار المالك | لا تبدأ إلا بطلب صريح؛ يجب أن يظل التسجيل المحلي مستقلًا عن الشبكة |
