### استيراد CSV وXLSX

- مستورد الملفات Android Storage Access Framework عبر MethodChannel؛ لا يطلب صلاحية عامة لقراءة كل الملفات. الحد الأعلى للملف 25 MB.
- الأعمدة المطلوبة: `S/O` (كود العامل) و`Name`. الاختيارية: `Designation` و`Supplier`. يمكن وجود `ID No.` لكنه يُهمل ولا يخزن.
- يقبل CSV UTF-8 بفاصل comma `,` وعلامة نص مزدوجة `"`. يتعامل المحلل مع الحقول المقتبسة. يرفض كودًا أو اسمًا فارغًا، ويرفض تكرار الكود (بلا حساسية لحالة الأحرف).
- عند تحديث كود موجود، تُحدّث بيانات الاسم/المسمى/المورد ويحافظ المستورد على إسناد الفريق والسكن الحالي.
- في XLSX يقرأ المستورد ورقة باسم `All Labour Active` إن وجدت؛ وإلا يقرأ **أول ورقة فقط**. CSV في LibreOffice يصدر الورقة النشطة فقط. تأكد من اختيار ورقة القوى الكاملة قبل التصدير؛ ملفات CSV متعددة الأوراق لا توجد.
- ملف القوى الذي فُحص يدويًا كان بنية أعمدته صحيحة: `S/O`, `ID No.`, `Name`, `Designation`, `Supplier`؛ 115 صف بيانات، دون كود مكرر أو حقول كود/اسم ناقصة. لكن ترميزه كان Windows-1256، والمحلل يشترط UTF-8؛ لم تُنسخ أي أسماء أو أرقام هوية من الملف إلى Git أو التقرير.
- إعداد تصدير LibreOffice: `File > Save As > Text CSV (*.csv)`، ثم Character set = `Unicode (UTF-8)`، Field delimiter = comma `,`، String delimiter = double quote `"`. يمكن إبقاء `Quote all text cells` محددًا. ألغِ `Save cell formulas instead of calculated values`. احتفظ بنسخة المصدر XLSX، وصدّر CSV جديدًا.
- لا يدعم التطبيق حاليًا الامتداد القديم `.xls` أو امتدادًا غير معتاد مثل `.xcl`؛ احفظ كـ`.xlsx` أو CSV UTF-8.

## الأخطاء السابقة وأسبابها ومنع تكرارها

### B-001 — التطبيق القديم شاشة بيضاء

- **السبب:** `MaterialApp` كان يحتوي `Scaffold` فارغًا.
- **المعالجة:** إضافة تدفق بدء التشغيل وواجهة Material 3 والتصفح والشاشات المحلية. صور المالك أكدت فتح APK أقدم وعرض الشاشات الأساسية؛ الوظائف الأحدث تحتاج تجربته على الهاتف.

### B-002 — ADB لا ينشئ `.android`

- **السبب:** بيئة تشغيل المضيف لا تسمح لـADB بإنشاء مجلده الافتراضي.
- **التأثير:** لا يمكن اعتبار ADB أو تثبيت الهاتف متحققًا من بيئة هذه الجلسة.
- **المتابعة:** يستخدم المالك CMD على جهازه/حسابه العادي عند رغبته في توثيق تثبيت أو تشغيل جديد.

### B-003 — Android/Gradle يفشل قبل البناء

- **الأعراض والأسباب:** تعارض متغيرات Android SDK القديمة؛ عدم القدرة على قراءة Git من داخل Flutter SDK؛ كتابة كاش Gradle/Pub؛ ومسار TEMP/ملف rollback الخاص بـKotlin.
- **المعالجة:** استخدام إعدادات Android متسقة، الإبقاء على السكربت المحلي، وتوجيه TEMP/TMP و`java.io.tmpdir` إلى scratch محلي. بعد ذلك نجح Release.
- **ممنوع:** `flutter clean` أو حذف الكاشات؛ لم تكن المشكلة في تلف شيفرة التطبيق.

### B-004 وB-006 — أخطاء Dart/S6

- **الأعراض:** import أحداث ناقص، صياغة collection و`const` غير مقبولة مع constructors Drift، brace ناقص بعد نقل منسق الرسالة، ونوع قديم `List<String>` غير متوافق مع سجل العامل typed.
- **المعالجة:** imports صحيحة، إصلاح صياغة Dart وترتيب `part`، إزالة `const` غير المناسب، ونقل تنسيق الرسائل ونماذجها إلى domain. أثبت analyzer والاختبارات النتيجة.

### B-005 — اختبار Flutter لا يبدأ في Sandbox

- **الأعراض:** رفض نسخ test listener إلى Temp، ثم `SocketException` على 127.0.0.1، وأحيانًا انتظار Flutter startup lock.
- **السبب:** قيود المضيف على temp والـloopback أو قفل أداة متزامن؛ ليست أخطاء business logic.
- **المعالجة:** سكربت `android-env.cmd` لإعداد temp/cache، وإتاحة loopback لمشغل الاختبارات. لا تحذف lockfile يدويًا، ولا تضف INTERNET إلى التطبيق كحل للاختبار. بعد الإصلاح اجتازت مجموعة الاختبارات كاملة.

### B-007 — ملف بيانات شخصية داخل docs

- **العَرَض:** عُثر على نسخة roster محلية في `docs/database.csv` تشمل بيانات هوية وأسماء.
- **المعالجة:** أزيلت النسخة، وسُجلت المشكلة دون الاحتفاظ بقيم شخصية. لا تسترجعها ولا ترفع ملفات القوى.

### B-008 — ترحيل المورد واختبارات المعمارية

- **الأعراض:** v1→v3 حاول إضافة `supplier` مرتين؛ اختبار المعمارية رفض اعتماد شاشة عرض على Drift أو feature آخر؛ واختبار v2 migration لم يجهز جدول Settings المتوقع.
- **المعالجة:** إضافة العمود لمسار v2→v3 فقط، نقل auth/admin screens إلى app composition layer، وعزل العرض عن التخزين عبر controller وعقود domain، وتجهيز fixture مطابق لقاعدة التشغيل.
- **التحقق:** الحالات نجحت ضمن 73/73.

### B-009 — نافذة تغيير كلمة المرور لا توضح الرفض

- **السبب:** حد الخدمة 8 أحرف؛ في النسخة الحالية شرط الضغط يرجع بلا رسالة إذا كانت كلمة التغيير أقصر من 8 أو لم يطابق التأكيد.
- **الحل للمستخدم:** اختر كلمة 8 أحرف أو أكثر واكتبها نفسها في التأكيد. كلمة المرور الجديدة التي اختارها المالك تبقى سرًا ولا تسجل في الوثائق.
- **قرار المالك:** أفاد بأن العملية اشتغلت لاحقًا، وطلب عدم تعديل التطبيق. لذلك لا تغيّر هذه النافذة الآن؛ سجّل defect UI المفتوح وأصلحه فقط بطلب جديد.

### B-010 — CSV بترميز Windows-1256

- **السبب:** ملف القوى سليم الأعمدة لكنه ليس UTF-8، بينما parser يستعمل UTF-8 صارمًا.
- **الحل:** أعد تصديره من LibreOffice كـText CSV مع Unicode (UTF-8)، delimiter comma، وtext delimiter `"`. تأكد من الورقة النشطة لأن CSV يحفظ ورقة واحدة فقط.
- **الخصوصية:** لا تحفظ نسخة القوى في المستودع أو docs أو مخرجات الاختبار.
