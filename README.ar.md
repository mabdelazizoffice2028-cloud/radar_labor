## 📋 نبذة عن المشروع (Overview)

صُمم تطبيق **«رادار ليبور» (Radar Labour)** خصيصاً لتلبية متطلبات الشركات والمقاولات الكبرى في رصد وإدارة العمالة الميدانية، والتحقق اليومي من نزلاء المجمعات السكنية (Camp Housing)، وضبط حركات الحضور في مواقع العمل والمشاريع الإنشائية والصناعية المتباعدة.

تعتمد الأنظمة السحابية التقليدية وأجهزة البصمة الحيوية على توفر الاتصال الدائم بالإنترنت، وهو ما يندر وجوده في المواقع الصحراوية والنائية ومراكز المشاريع قيد التأسيس. يؤدي هذا الانقطاع إلى هدر تشغيلي، عمالة مجهولة الموقف، صعوبة مطابقة فواتير شركات التوريد والتأجير، ومخاطر نظامية تتعلق بانتهاء الوثائق الرسمية.

يحل **«رادار ليبور»** هذه الإشكاليات عبر بنية برمجية **محلية أولاً (Local-First / Offline-First)**:
* **استقلالية تامة في الميدان:** تُجرى كافة عمليات الفحص والتسجيل وتدقيق القوائم دون الحاجة إلى شبكة الإنترنت، بالاعتماد على قاعدة بيانات SQLite مشفرة محلياً على الجهاز.
* **سجل أحداث غير قابل للتعديل (Append-Only Event Ledger):** تُقيد كل حركة ميدانية على شكل حدث تراكمي تسلسلي، مما يمنع التلاعب بالبيانات أو فقدان التزامن ويضمن موثوقية السجلات التاريخية.
* **شفافية فورية للإدارة:** معالجة تلقائية للتعارضات الميدانية، وتنبيهات حية بتجاوز اتفاقيات مستوى الخدمة (SLA)، واستخراج تقارير عملياتية فورية للواتساب تدعم اللغتين العربية والإنجليزية بضغطة زر واحدة.

## 🚀 أبرز التحديثات الأخيرة (What's New)

* **🌙 استثناء يوم الجمعة والعمل الإضافي (Friday Overtime & Zero-Absence):** تطبيق قاعدة راحة الجمعة الرسمية بضمان صفر غيابات في كافة أنحاء التطبيق؛ العمال المختارون يسجلون كـ «عمل إضافي» مع شريط تنبيهي عنبري متباين وتكييف بطاقات لوحة التحكم وتقارير الواتساب الميدانية.
* **🧪 تدقيق الجودة الشامل واجتياز 213 اختباراً آلياً:** اجتياز 213 اختباراً بنسبة نجاح 100%، متضمنةً اختبارات صمود المسودات ضد الإغلاق المفاجئ، التراجع الذري، معالجة نزاعات المشرفين، واختبارات الأداء العالي (معالجة 1,500 عامل في 40 ملي ثانية).
* **👥 زر تحديد الفرقة المعتادة (Default Crew):** زر بلمسة واحدة لمشرف الموقع لتحديد أعضاء فريقه النظاميين دفعة واحدة، مما يتيح له فقط استثناء الغائبين وحفظ الكشف بسرعة فائقة.
* **⚡ حضور تلقائي للكادر الإداري والفني:** معاملة المهندسين ومسؤولي السلامة والإداريين والمراقبين كـ «حاضر بالموقع تلقائياً» يومياً، مع إتاحة تسجيل غيابهم بنقرة واحدة من قِبل الإدارة.
* **🏖️ إدارة الإجازات المرنة والتاريخية:** تسجيل وتتبع إجازات العمال السابقة والمستقبلية، واستبعاد العمال المجازين تلقائياً وفورياً من قوائم التحضير والغياب ولوحة التحكم (الغياب = 0).
* **📋 بطاقة العامل الشاملة وسجل الفرق:** بطاقة تفاعلية تنبثق عند النقر على أي عامل لعرض 3 مؤشرات واضحة (أيام العمل الفعلية شاملة الغياب المبرر، أيام الغياب الفعلي، وسجل العمل مع الفرق)، وإدارة الإجازات، وتبديل غياب اليوم.
* **🛡️ ترقية وتوحيد دور Admin:** اعتماد مسمى «Admin / الإداري» في كافة شاشات التطبيق كبديل لدور الموارد البشرية القديم.
* **🔔 مركز إشعارات متكامل ومستقل (Notification Center):** تفريغ لوحة التحكم الرئيسية من البطاقات الصفراء المربكة، وإضافة جرس إشعارات تفاعلي في الشريط العلوي (`NotificationBadge`) يفتح نافذة سفلية أنيقة (`NotificationsSheet`) تعرض حالة المزامنة اللحظية والفرق أو المساكن التي لم تُسجل اليوم.
* **🪪 الرقابة الاستباقية على صلاحية الإقامات:** بطاقة تنبيه ذكية في لوحة المتابعة تكشف العمال المنتهية إقاماتهم أو التي تشارف على الانتهاء خلال 30 يوماً مع درج تفصيلي للمراجعة السريعة.
* **📊 مولّد التقرير اليومي الموحد للواتساب:** توليد ملخص عملياتي تنفيذي يومي شامل، يصنف الحضور والغياب للعمالة المباشرة وعمالة شركات التأجير، ومقيد تلقائياً بساعة الإغلاق المعتمدة بتوقيت الرياض.
* **🔄 محرك التصحيح التلقائي المزدوج (Auto-Fix):** تصحيح التعارضات آنياً؛ عند تسجيل العامل كـ «حاضر بالموقع»، يقوم النظام ذرياً بإلغاء تسجيل غيابه في السكن لذلك اليوم وتسجيل الحركة في السجل التاريخي.
* **🔍 البحث الفوري بآخر 4 أرقام (Suffix Search):** فلترة فورية لكشوفات العمال بمجرد كتابة آخر 4 أرقام من رقم الإقامة، مما يسرع عمليات الفحص الميداني بعشرة أضعاف.
* **🛡️ استيراد صارم للقوى العاملة (Strict Import):** آلية استيراد مشددة لملفات XLSX/CSV تشترط صحة أرقام الإقامات (10 أرقام)، وتمنع التكرار، وتقوم بإلغاء المعاملة بالكامل (Rollback) في حال وجود خطأ واحد.
* **🧹 أداة الإدارة لتصفير بيانات التجارب:** أداة آمنة ومحمية في شاشة الإعدادات تمكّن المشرف من مسح أحداث الحركات التجريبية وتصفير اللوحة بأمان تام دون المساس ببيانات العمال أو الفرق.
* **🌐 محدد فوري للغة في شاشة الدخول:** إضافة زر تبديل اللغة (عربي / English) في أعلى واجهة تسجيل الدخول مع حماية متكاملة من حجب لوحة المفاتيح عبر التصميم المتجاوب.

## ⚡ الميزات والوحدات الرئيسية (Core Features & Modules)

### 👷 1. إدارة القوى العاملة والامتثال (Workforce & Compliance)
* **ملفات عمال موحدة وشاملة:** تسجيل بيانات العامل برقم كود فريد، ورقم إقامة نظامي من 10 أرقام، واسمين بالعربية والإنجليزية، مع ربطه بمهنته وجهة توريده وسكنه وفريقه.
* **متابعة الوثائق والإقامات:** نظام تدقيق زمني يرصد الإقامات منتهية الصلاحية وتلك القريبة من الانتهاء، لتجنب الغرامات والمخالفات التنظيمية.
* **معالج الاستيراد الجماعي:** دعم كامل لملفات Excel (.xlsx) و CSV حتى حجم 25 ميجابايت مع فحص أولي للمطابقة قبل الحفظ.

### 📍 2. تسجيل حضور الموقع الميداني (Site Attendance)
* **توزيع الفرق والورديات:** إسناد العمال لفرقهم الميدانية ومشرفيهم بدقة.
* **فصل التخصصات والمشغلين:** تمييز فوري بين العمالة العامة ومشغلي المعدات الثقيلة (Operators) في الكشوفات والتقارير.
* **تسجيل الحضور والعامل الضيف:** اعتماد كشوفات الحضور بنقرة زر مع إمكانية استدعاء عمال إضافيين أو ضيوف مؤقتين من فرق أخرى.
* **اعتماد الحضور الصفري الآمن:** إمكانية إرسال تقرير رسمي عند توقف العمل (صفر حضور) مع حماية سجل الالتزام التشغيلي.

### 🏠 3. فحص ومراجعة سكن العمال (Campus Housing Check)
* **فحص السكن ثلاثي الحالات:** تقييم مرن للعمال بنمط: (`لم تتم المراجعة` / `تمت المراجعة وهو حاضر` / `غائب`).
* **زر التأكيد السريع «لا يوجد غياب اليوم»:** اعتماد حضور كافة نزلاء السكن بضغطة زر واحدة عند اكتمال وجودهم.
* **تقارير الغياب المفصلة:** فصل غياب عمال الشركة عن عمال مقاولي الباطن والشركات الموردة بدقة.

### ⚡ 4. سجل الأحداث الذري والمزامنة الصامتة (Event Ledger & Sync)
* **سجل الأحداث المتراكم (`events`):** تسجيل كل عملية كحدث غير قابل للتعديل، مع أحداث تعويضية عاكسة عند التراجع (ضمن نافذة سماح مدتها 5 ثوانٍ).
* **معالجة التعارضات الميدانية:** بطاقة مقارنة ذكية تعرض الفروقات التشغيلية بين تسجيل الموقع والسكن لاختيار القرار المناسب بوضوح.
* **المزامنة التلقائية الصامتة:** رفع الحركات المعلقة في صندوق العمليات فور توفر الاتصال دون مقاطعة سير عمل المستخدم الميداني.

### 🔒 5. الأمان وإدارة الصلاحيات (Security & RBAC)
* **صلاحيات متعددة الأدوار (RBAC):** عزل أمني بين مهام: مدير المشروع، مسؤول الموارد البشرية، مشرف السكن، مشرف الموقع، والمشاهد فقط.
* **تشفير محلي عسكري:** تشفير قاعدة بيانات SQLite محلياً عبر خوارزميات AES-256 مع حماية المفاتيح داخل مستودع أمان النظام (Android KeyStore).
* **سياسة كلمات المرور:** تشفير الرموز السرية بخوارزمية Argon2id، وإلزامية تغيير الرمز المؤقت عند أول دخول، وقفل الحساب عند المحاولات المتكررة الخاطئة.
* **ساعات القفل بتوقيت الرياض:** إقفال تلقائي يمنع التعديل الميداني بعد الساعات المقررة (الساعة 20:00 لقفل السكن، والساعة 23:00 لقفل الموقع).

### 💬 6. محرك قوالب الواتساب الميداني (WhatsApp Engine)
* **رسائل مهنية منظمة:** توليد كشوفات يومية مهيأة للنسخ والمشاركة المباشرة عبر مجموعات الإدارة والمقاولين في الواتساب.
* **صفر تكاليف تشغيلية:** التوليد يتم محلياً بالكامل على المعالج دون استهلاك باقات أو الاعتماد على بوابات ربط خارجية مدفوعة.

## 🏛️ الهيكل البرمجي للمشروع (Project Structure)

يعتمد المشروع معمارية نظيفة مجزأة دقيقاً (**Feature-First Micro-Modularization**) مع الالتزام الصارم بحد الـ 80 سطراً لكل ملف لضمان سهولة الفحص والصيانة:

```text
lib/
├── app/                              # إعدادات التطبيق، التوجيه، والواجهات العامة
│   ├── accounts/                     # إدارة الحسابات المحلية وإسناد المشرفين
│   ├── screens/                      # الهياكل والشاشات العامة العليا
│   └── widgets/                      # الـ Widgets المشتركة (مركز الإشعارات، بطاقة الدخول)
│
├── core/                             # البنية التحتية والوحدات العابرة للتطبيق
│   ├── audit/                        # سجل التدقيق وتحديد هويات الأجهزة
│   ├── auth/                         # مستودعات المصادقة ونطاقات الصلاحيات
│   ├── constants/                    # الثوابت، الحدود الزمنية، والاتفاقيات التشغيلية
│   ├── database/                     # مخططات وقواعد Drift وعمليات الترحيل والتشفير
│   │   ├── models/                   # كائنات نقل البيانات لقاعدة البيانات
│   │   └── tables/                   # جداول النظام (العمال، الأحداث، الفرق، الصلاحيات)
│   ├── l10n/                         # النصوص والرسائل المترجمة (عربي / إنجليزي)
│   ├── status/                       # محرك حساب الحالات اليومية وتجاوزات SLA
│   ├── sync/                         # محرك المزامنة وصندوق العمليات المعلقة
│   └── ui/                           # ثيمات الواجهة، AppSnackBar، والاستجابة اللمسية
│
└── features/                         # الوحدات الوظيفية المستقلة
    ├── dashboard/                    # لوحة المؤشرات، تنبيهات الإقامات، والتقرير اليومي
    │   ├── data/                     # مستودعات التغطية ومجمع التقرير اليومي
    │   ├── domain/                   # نماذج المؤشرات والحسابات الإجمالية
    │   └── presentation/             # بطاقات اللوحة، حوارات التعارض، والشرائح السفلية
    │
    ├── operations/                   # عمليات تسجيل حضور الموقع ومراجعة السكن
    │   ├── data/                     # مستودعات الحضور، نقاط السكن، وإعداد الفرق
    │   ├── domain/                   # قواعد العمل، قوالب الواتساب، وحمايات النطاق
    │   └── presentation/             # شاشات الفحص الميداني وحالات Notifiers
    │
    └── roster/                       # دليل القوى العاملة والاستيراد الميداني
        ├── data/                     # مستودع استيراد العمال وقراءة الملفات
        └── domain/                   # مدققات صحة البيانات ونماذج المعالجة
```

## 💻 بيئة التطوير والتشغيل المحلي (Developer Guide)

### المتطلبات الأساسية (Prerequisites):
* **Flutter SDK:** الإصدار 3.47.x أو الإصدار المستقر الأحدث
* **Dart SDK:** 3.13.5 فما فوق
* **حزمة تطوير جافا:** JDK 17
* **Android SDK:** المستوى API 34 فما فوق

### خطوات البدء والتشغيل:

1. **استنساخ المستودع (Clone):**
   ```bash
   git clone https://github.com/your-org/radar_labor.git
   cd radar_labor
   ```

2. **تثبيت الحزم (يفضل استخدام الكاش المحلي):**
   ```bash
   flutter pub get --offline
   ```

3. **إجراء الفحص الساكن للكود (Static Analysis):**
   ```bash
   flutter analyze --no-pub
   ```
   *النتيجة المتوقعة: `No issues found!`*

4. **تشغيل كامل حزمة الاختبارات الآلية (185+ اختباراً):**
   ```bash
   flutter test --no-pub
   ```
   *النتيجة المتوقعة: `All tests passed!`*

5. **تشغيل التطبيق في وضع التطوير (Debug):**
   ```bash
   flutter run --no-pub
   ```

6. **بناء نسخة الإنتاج المخصصة للأجهزة الحديثة:**
   ```bash
   flutter build apk --target-platform android-arm64 --release --no-pub
   ```
